👀 그랜저·카니발 HEV 승계 감시

매주 월요일 자동 수집. 진짜 승계(계약 경과 ≥ 2개월)만 기본 표시, 신규계약 포장·저주행 의심·영구삭제 매물은 제외. 월 총비용 = 만기까지 타는 비용 (월료×잔여 + 인수금 − 지원금 − 보증금)÷잔여 + 미포함 항목(보험 10·자동차세 2.5·정비 3, 포함된 건 0). 만기판단 = 예상 만기시세(같은 모델 일반매물 회귀로 만기 시점 연식·주행 반영) − 인수가×1.07(취득세): +면 인수(승계 후 매입) 유리, −면 반납 유리 — 월 총비용에는 넣지 않은 참고값. 만기 주행은 연 25,000km 가정. 예상 시세는 엔카 판매 호가 기준이라 딜러에 되팔면 보통 5~10% 낮음. 보증금은 승계자에게 환급(반납)·상계(인수)된다는 전제 — 계약서로 확인. 렌트 인수가는 엔카 등록값(변동 가능) — 렌트사 확인. 단위 만원. 🚗 = 고속도로 주행보조 2(스마트센스 II / 드라이브 와이즈) 포함.
